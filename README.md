⚡ The Lantern at Hogwarts

Every Muggle has a first step into the Wizarding World.

The Lantern at Hogwarts is an unofficial, fan-made interactive Harry Potter-themed website created as a frontend portfolio project.

✨ Features

🪄 Muggle → Wizarding World introduction

🏰 Hogwarts-inspired UI and animations

🎬 Seven-part story/movie roadmap

📖 Read / 🎬 Watch / 🛒 Buy actions

🧙 Character library with See More

✨ Spells, objects, places, houses and creatures

🎮 Wizarding games section

🧩 Five-question quiz after each story entry

🔓 Quiz-based progression/unlocking

💾 Browser-side progress with localStorage

💬 Quote section with attribution

📱 Responsive mobile-friendly UI

🚀 Static deployment — no backend required

🛠️ Tech Stack

HTML5 • CSS3 • Vanilla JavaScript (ES6+) • localStorage • GitHub • Vercel

☁️ Deploy

Push the project to GitHub, then import the repository into Vercel. No backend or database is required.

🧩 Quiz System

The quiz can be implemented entirely with JavaScript. A visitor answers five questions after a story entry. If all five are correct, JavaScript stores the unlocked state in localStorage and reveals the next entry.

Example:

localStorage.setItem("chapter2Unlocked", "true");

This is client-side progression, so it is intended for a portfolio/demo rather than secure authentication.
